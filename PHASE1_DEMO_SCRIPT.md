# Phase 1 demonstration (2–3 minutes)

1. **Overview:** “Phase 1 monitors workflows automatically generated by EvoAgentX, captures their graph structure, collects execution traces, extracts available features, and creates datasets.”
2. **Run EvoAgentX:** Enter a goal and run it. Explain that `WorkFlowGenerator` creates the workflow graph and assigns agents; the application does not manually define a fixed task sequence.
3. **Generated graph:** Show the actual nodes, assigned agents, edges, workflow inputs, and outputs returned by EvoAgentX.
4. **LangSmith Monitor:** Test the connection and retrieve the actual traces from the configured LangSmith project.
5. **Feature Extraction:** Extract available timing, token, error, tool/LLM call, depth, and failure-rate features.
6. **Dataset:** Show the generated graph JSONL, raw LangSmith run CSV, and trace-level feature CSV.

Only call a workflow successful if EvoAgentX reports `success`. Only call traces real if they have been retrieved from LangSmith. Internal agent/model spans require deeper instrumentation if LangSmith shows only the generation/execution parent spans.
